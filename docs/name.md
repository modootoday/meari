# The name

Meari (메아리) is the Korean word for *echo*, and is also read as **Multi-platform Experience Across Renderers Interface**. One TSX source is the voice; the Rust Native renderer and the React Web adapter are its echoes, which should come back looking the same. That is the tagline, *Write once, echo everywhere.*, and it is what `cargo xtask visual-test` checks pixel by pixel.
